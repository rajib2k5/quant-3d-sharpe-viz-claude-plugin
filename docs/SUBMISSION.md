## Listing text

**One-line description**

> Screen stocks by Sharpe ratio and alpha with a statistical luck correction, then explore the result as a 3D skyline.

**Longer description**

> Sharpe Observatory ranks a stock universe by risk-adjusted return and asks how much of the top of the list is just luck. It computes annualized Sharpe ratios, CAPM and Fama-French 3 alphas, the Probabilistic Sharpe Ratio and the Deflated Sharpe Ratio. It compares every name with the Sharpe ratio the best of N luckless names would be expected to reach (the False Strategy Theorem), and reports how many of the top 20 pass DSR >= 0.95. It runs offline on a bundled synthetic sample, or, on request, on the live S&P 500, the full US market (about 5,900 stocks) or your own ticker list. Results render as a 3D skyline: a PNG that needs no extra installation, or an interactive page with click-to-inspect details and a luck plane. An educational statistics tool, not investment advice.

## Data handling

| Question | Answer |
|---|---|
| What user data is collected? | None. No telemetry, analytics, accounts or sign-in. |
| What is transmitted, and to whom? | Offline mode transmits nothing. Live mode (`--live`, only when the user asks) sends requests for public market data directly to the disclosed sources (below); requests carry ticker symbols or data-series names only. |
| Disclosed hosts (live mode) | `raw.githubusercontent.com` (S&P 500 list); `en.wikipedia.org` (fallback only); `www.nasdaqtrader.com` (`--index us-all` only); Yahoo Finance via yfinance (`query1`/`query2.finance.yahoo.com`, possibly `fc.yahoo.com`, `finance.yahoo.com`, `guce.yahoo.com`, `consent.yahoo.com` for a session cookie); `fred.stlouisfed.org`; `mba.tuck.dartmouth.edu`. |
| Interactive page | Loads three.js from `cdn.jsdelivr.net`. Links to `www.google.com`, `www.sec.gov` and an optional user-supplied company website open only when the user clicks them. |
| Credentials, API keys, tokens | None required, none requested, none stored. |
| Local storage | Output files in a user-chosen folder; optional `--cache-dir` price CSVs; yfinance's own time-zone and cookie cache under the user cache directory (live mode only). |

## Reviewer test path

The offline sample mode needs no account, key or network access to market data:

1. Install the plugin and `pip install -r requirements.txt`.
2. Prompt: "Screen the sample universe by 3-year Sharpe and tell me how many of the top 20 have a deflated Sharpe of at least 0.95."
   - Expected: 60 synthetic names, luck plane at Sharpe 2.41, "1 of 20" pass (TEC03), with the not-investment-advice note.
3. Prompt: "Make the three.js skyline page for the 5-year window and explain the colours."
   - Expected: a PNG (matplotlib, so no Blender needed) and `out/skyline.html`, which loads three.js from the CDN when opened.
